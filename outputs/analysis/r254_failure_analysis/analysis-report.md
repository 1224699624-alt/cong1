# R254 近距离骨缝粘连失败分析

## 分析问题

比较同一批 96 张 original-val 图像上的 nnU-Net native continuation 与 HA-PDSP+PCR，判断首版方法是否真正减少近距离骨间粘连。

比较单位是同一图像的配对结果。当前只有 1 个训练 seed，而且 original-val 同时用于 checkpoint 选择，因此统计结果只能用于诊断，不能作为独立泛化显著性结论。

## 核心发现

1. **最直接的骨缝指标明确变差。** gap-region FP rate 平均增加 0.04119，95% paired bootstrap CI 为 [0.03662, 0.04600]；96 张图中绝大多数方向为恶化。
2. **掩膜发生前景膨胀。** Recall 增加 0.01420，但 Precision 降低 0.01768。这不是“既保骨又分缝”，而是预测覆盖了更多骨头同时也覆盖了更多骨缝背景。
3. **局部边界质量下降。** Boundary IoU 降低 0.00623，Surface Dice 2 px 降低 0.01240，说明普通边界和窄缝轮廓整体更不准确。
4. **HD95/ASSD 改善不能解释为骨缝改善。** 它们主要受远距离漏检、孤立碎片和极端表面误差影响；本次 component count 变得更接近 GT，可能减少了远端碎片，所以距离指标改善，但 gap FP 和 merge rate 没有改善。
5. **训练 anchor 指标与真实近缝指标脱节。** selected-anchor foreground probability 从 0.839 降至 0.051，但验证 gap FP 反而增加。这证明当前 anchor 主要覆盖了容易的宽背景或错误位置，没有覆盖截图中的最近骨对瓶颈。

## 截图对应的失败机制

两张截图都属于“多个骨块距离非常近，阈值后由窄桥连接为一个组件”。现有实现使用形态距离作为可靠性门槛，要求候选背景离前景约 2.5 px 以上。这会系统性跳过只有 1–2 px 的真实窄缝，而这些正是最容易在推理时闭合的区域。

同时 robust base 对 foreground core 和 far background 分别归一化并近似等权。骨头前景占比很小，单独归一化的 core BCE 会产生较强的前景恢复压力，使轮廓变厚。结果就是 Recall 上升、Precision 和 gap FP 变差。

## 决策变化

当前方法不能通过“骨缝粘连改善”门槛。下一版不能调大现有 PCR 权重，而应重定义候选位置：

- 只激活同一预测连通域中匹配到两个独立实例支持的近距离骨对；
- 1–2 px 窄缝的可靠性改由实例身份和 X 光局部证据决定，不再要求远离前景；
- 恢复 canonical nnU-Net Dice/CE，删除造成前景膨胀的等权 core BCE；
- 对最短边界间隙/预测瓶颈计算背景 BCE 与骨—缝置信排序损失；
- 无原标签背景像素时仍严格跳过，不构造反向骨缝标签。

clean-test-v2 继续锁定。
