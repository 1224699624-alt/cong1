# R254 统计附录

## 数据与限制

- 配对图像：96 张 original-val。
- 训练 seed：1。
- 方法和对照使用同一初始化 checkpoint、相同额外 epoch/iteration、相同 LR。
- original-val 参与 checkpoint 选择，因此 p 值与区间仅作内部诊断。
- 对每个指标使用图像级 paired bootstrap 20,000 次计算均值差 95% CI。
- 使用双侧 Wilcoxon signed-rank test，并对 13 个指标进行 Holm 校正。
- 效应量为配对 rank-biserial correlation。

## 决策相关指标

| 指标 | ours-baseline 均值差 | 95% CI | Holm p | 解释 |
|---|---:|---:|---:|---|
| Dice | -0.00360 | [-0.00833, 0.00009] | 0.0091 | 小幅下降，分布偏斜 |
| Precision | -0.01768 | [-0.02243, -0.01363] | <1e-14 | 明确增加 FP |
| Recall | +0.01420 | [0.01228, 0.01670] | <1e-15 | 捕获更多前景 |
| Boundary IoU | -0.00623 | [-0.00902, -0.00354] | 0.00014 | 边界明确变差 |
| Surface Dice 2 px | -0.01240 | [-0.01729, -0.00764] | 0.000034 | 近表面一致性变差 |
| gap-region FP | +0.04119 | [0.03662, 0.04600] | <1e-15 | 骨缝背景填充明确恶化 |
| HD95 | -13.776 px | [-32.278, 0.549] | 0.00046 | 少数极端病例主导；不能证明骨缝改善 |
| ASSD | -1.691 px | [-7.165, 1.880] | <1e-7 | 分布/均值受极端病例影响 |
| merge rate | +0.01042 | [-0.05208, 0.07292] | 1.0 | 无改善证据 |
| component MAE | -1.27083 | [-3.83359, 0.15625] | 1.0 | 可能减少碎片，但证据不稳定 |

HD95/ASSD 的 Wilcoxon 与均值 bootstrap CI方向不完全一致，说明差值高度偏斜并受极端病例影响。因此这里只保留“部分病例的远距离表面误差减少”，不解释为普遍改善。

完整数值见 paired_statistics.csv。
