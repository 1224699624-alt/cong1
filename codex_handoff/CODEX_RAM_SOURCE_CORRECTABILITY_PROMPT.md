## 2. 第一个动作：零更新的“错误集合贡献”检查

### 2.1 固定模型、推理和阈值

优先复用C0已有逐例source/step1/step2预测；缺失才做固定权重推理。保持原生空间处理、canonical flip、padding、valid、成员顺序及原R329标准评价。

锁定用于诊断的完整14成员推理精度、线程设置、sigmoid及阈值实际路径。不要混用 `logit>=0` 与不同精度下的 `sigmoid>=0.5` 后假定边缘计数必然一致。标准分割预测继续用原评价协议。

所有GT关系计算在前向结束后进行，模型forward不得读取GT。

### 2.2 定义固定初始困难集合

在成员标注完整且有效区域：

`H0[k,x] = valid[x] AND (GT[k,x]=1) AND (sum_k GT[k,x]>=2)
            AND (C0_final_prediction[k,x]=0)
            AND (C0_source_logit[k,x] < -5-1e-5)`

训练集和验证集分别生成、分别存放。训练/验证集合不能混用。

统计：
- 像素×成员数、唯一像素数、每病例/每成员分布；
- H0所在像素中，C0最终预测成员数为0、1、>=2的分布；
- 其中多少只需恢复一个成员就能把global overlap FN改为TP，多少需要恢复至少两个；
- H0之外的重叠成员FN规模；重叠/非重叠的成员FN率分别以各自GT正成员数为分母。

68.03%的FN位于重叠区是错误构成比例，不等于重叠区的条件漏分率。

### 2.3 仅离线的理想修正，不作为模型成绩

在C0保存的最终二值成员mask上构造独立诊断副本：

`P_oracle[k] = P_C0[k] OR H0[k]`。

保持其他像素不变，用原评价器与原聚合规则计算Overall/Overlap/Pair DSC及其他已有标准指标。不得覆盖原预测、训练模型或修改GT。

每条结果明确标记：`ORACLE_DIAGNOSTIC_NOT_MODEL_RESULT`。

回答：只把这批固定hard FN全部恢复、且不增加FP，Overlap DSC能增加多少？按原macro规则逐病例重算，不能用像素计数线性换算。

这只是“仅允许修复该集合”的理想误差消除潜力，不是模型可实现上限，也不是对NSD/距离单调改善的保证。

若该理想Overlap DSC增量仍小于0.01，明确“仅修H0不足以单独达到约1个百分点目标”。可继续有限可修正性诊断，但不再把H0修复宣传成达到全部目标的充分路径。若达到0.01，也不代表网络能达到。

## 4. 核心干预：可训练范围 × 监督覆盖与持续性的2×2

新run名称用 `SRC_F0S0` 等，不覆盖旧A/B/C/D、source_aux或身份实验。

| run | source路径可训练范围 | 困难source监督 |
|---|---|---|
| SRC_F0S0 | F0：现有范围 | S0：原R332目标 |
| SRC_F0S1 | F0：现有范围 | S1：原目标＋固定H0持续source监督 |
| SRC_F1S0 | F1：只额外开放一个source路径冻结块 | S0：原R332目标 |
| SRC_F1S1 | F1：同一个额外块 | S1：同一固定H0监督 |

四组从同一个C0开始，各自独立运行；不接着上一组训练，不顺序加载组间权重。

### 4.1 F1的含义必须精确

先画实际source路径，标出所有冻结/可训练块。特别区分backbone encoder/decoder和refiner自己的 `enc1` 等同名层。

F1只在**产生source logits的骨干路径**上，额外开放一个与当前可训练decoder相邻的连续冻结块；具体层名、参数量、分辨率、理由预先登记。不是全部解冻，也不是只修改末端refiner的编码器。

选择依据是实际冻结边界及信息/梯度位置，不是先猜某个层号。F1不能同时加特征通路、改变归一化、替换网络或调整残差上限。

### 4.2 S1的含义必须精确

- 保持原R332 source/global与四成员local的全部目标；新增项仅作用于训练集固定H0上的source logits。
- 对H0中的对应正确成员监督，不受本步是否选入4成员限制；跨过−5后也不退出新增项。
- 不向其他成员广播正标签；不把任何val困难集合或val新增FP放入目标。
- 原成熟成员负类、surface/volume等目标保留；本轮不再同时新增局部负类保护。

新增项形式：

`L_H = lambda_H * sum(H0_transformed * softplus(-source_logits)) / D_batch`。

优先复用已运行source_aux中可追溯的直接BCE尺度：报告中的系数为2.2，分母为 `sum(1+3*original_selected_local_mask)`。**在本地核实其张量范围、valid及sum的真实定义后，才锁定相同尺度与分母实现。**不要凭报告片段自动改成hard像素均值，或另乘一个巨大权重。

四组都记录同一个L_H诊断值，只有S1组将它加入训练目标。D_batch随固定数据/目标规则确定，不依赖本组当前预测改变归一化以回避难例。

S1相对旧source_aux同时改变了“覆盖选中/未选中成员”和“支持持续性”，所以本轮只能解释为**困难监督交付方案的组合效应**，不单独宣布其中一项是唯一主因。若组合有效，下一轮才考虑拆分。

不预填新正margin、不调大LR、不搜索lambda；先单测梯度符号、归约和有效量级。若无法恢复上述实际数学定义，先给出具体阻塞，不用猜测公式开跑。

### 4.3 固定四成员选择，避免训练对象混杂

为本轮机制诊断，使用C0、已锁数据/增强序列和原成员选择函数，预生成每一步的四成员ID。四组重放同一序列。

C0前向仅用于生成训练调度，不执行额外optimizer训练。原global与local监督公式不变，S1仅添加L_H。

明确这是一项**四组共同采用的新诊断协议**，不声称与旧模型依赖的动态选择完全同义。不能直接用旧100/850步分数替代本轮SRC_F0S0。若本轮有效，恢复原动态规则的外推验证留到下一轮。

## 6. 白盒轨迹：必须追踪“实际更新→margin→最终恢复”

不要只交loss曲线、参数非零或最终指标表。

### 6.1 固定H0上的source与两步修正

对更新集、本轮病例留出集、最终val69分别记录：

- C0及各预定快照的source logit、step1/step2 residual与最终logit；
- gate、tanh输出、残差符号及接近上限的比例；
- source低于−5、跨过−5及最终真正恢复三种计数，互不替代；
- H0的恢复数、唯一global overlap FN恢复数、具体骨对变化；
- 匹配负成员新FP、其他正成员新FN、普通区域变化。

实际翻转条件应按：

`z_final_0 = z_source_0 + delta1_0 + delta2_0`

`delta_z_source + delta_total_refinement >= -z_final_0`

理解。超过source=-5只是必要范围改善；不意味着refiner实际给足剩余正向修正。

除均值外，保留预登记分位数/直方图，避免少数大位移掩盖多数位置无变化。诊断计数不是新增主指标。

### 6.2 实际参数更新，而不只看梯度

对 source现有可训练块、新开放块、成熟refiner，记录：

`delta_theta_g = theta_after_step_g - theta_before_step_g`。

包括实际LR、参数/梯度/更新范数、累计偏移、更新元素比例、Adam一阶/二阶矩摘要、AMP及clip行为。旧routing若未启用，不为本轮新增；若原流程已有，沿原实际实现记录，不改变设置。

对固定困难目标：

`Q_H = mean_H0 softplus(-source_logits)`

在同一参数状态记录：

`alignment_g = dot(gradient_g(Q_H), delta_theta_g)`。

负值表示一阶近似有利，正值表示不利；还要记录同批更新前后Q_H的实际变化。分别看组贡献，不以一个全模型负点积替代所有困难位置获益。

对匹配真负成员记录相应source负类BCE与其方向；检查是否“推正一类，同时推正错误成员”。

### 6.3 观测不能改变被观测训练

诊断额外forward/backward使用隔离副本，或严格恢复RNG、梯度、模式与缓冲区；不得污染正常训练状态或重复optimizer.step。

详细梯度诊断只在预登记快照执行，例如首步、固定间隔与终点；每步仅轻量统计，不每步保存全部feature/权重。记录观测开销，并计入预算。

### 7.2 图像/标注复核

用训练数据、固定抽样规则导出少量原图—实际网络输入—成员标签对照，包含困难与匹配对照，不按改进组效果挑图。标记坐标变换、成员ID、匿名病例ID，隐藏实验arm与是否被恢复。

检查可直接验证的错位、通道/左右翻转、原始与处理后信号差异。对解剖轮廓是否可见、标注是否可信，需要合适的人工复核；Codex不能自行冒充医学标注专家。

无人工复核时写 `HUMAN_REVIEW_PENDING`。模型/线性探针学不会，不是标签错误证据；GT降采样可保留几何，也不证明原图灰度线索未丢失。

不修改GT、不删除病例。发现疑点独立登记，本轮标准结果保持原协议。

## 8. 标准评价、判别规则与结论边界

### 8.1 标准评价

沿用当前RAM原评价器、固定阈值及聚合，不在本轮顺手替换成其他论文/新版本实现：
- Overall/member DSC、IoU、NSD，以及已有MSD/VOE/RAVD；
- global Overlap DSC、NSD、MSD；
- 原骨对DSC、NSD、MSD及failure/有效分母。

保存逐case及原有效骨对记录，统一单位。[0,1]分数差0.01是1个百分点；0.0002是0.02个百分点，不误报。

从最终分割计算性能；source/residual/H0计数和oracle只是诊断。完整val69只在预登记的共同终点评价，不用中间val挑本轮系数、块位置、训练时长或最好epoch。

### 8.2 参照

- C0只做成熟能力保护参照，0新增更新；不是同预算训练因果对照。
- 主要因果比较是同预算SRC组之间；如两组都低于C0，不把“较少退化”宣传为超过成熟能力。
- 旧100/850步及不同诊断子集不直接相减解释新因素。
- 这轮单seed只作机制探索，不制造总体显著性/稳定提升声明。病例bootstrap若使用，只能如实说明配对单位和聚类限制，不能当成多seed证据。

### 8.3 预先写清支持与反驳信号

1. F0S1优于F0S0，且F1额外作用很小：优先支持监督交付方案；不声称共享特征毫无问题。
2. F1在相同S条件下改善，并在病例留出有一致方向：支持当前可训练范围受限；实际更新必须有效。
3. 只有F1S1有效：考虑特征×监督交互，不硬选单一原因。
4. 更新集修正、病例留出无效：更像特定样本拟合/泛化限制，不能直接延长训练追val。
5. 四组均不选择性修正：结合有效更新、特征读出和人工复核判断；证据不足时明确无法判定，而非宣布图像不可辨或nnU-Net无空间。
6. hard恢复但Overlap Dice或边界不改善：按唯一像素映射、错误成员与新增FP/FN解释，不以内部恢复宣布目标达成。

机制支持必须同时观察：目标获得有效暴露、实际更新朝预期作用、最终成员恢复及错误代价。只改善均值logit不够。

原有区域/边界保护要求继续保留；内部诊断是否值得扩大与是否达到正式性能目标分开报告。约+1个百分点是目标尺度，不是本轮诊断必须先达到才能有价值，也不是允许放宽其他指标的理由。
