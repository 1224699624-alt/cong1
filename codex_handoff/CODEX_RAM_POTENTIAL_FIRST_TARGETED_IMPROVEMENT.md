## 2. 首先明确“潜力”是哪一层

必须区分以下四层，不能相互替代：

1. **机会量**：GT理想修复能提高多少，已分析，不是本轮重点。
2. **可学习性**：真实模型仅使用可部署输入，是否能在固定训练病例上实际修正困难成员，而不靠大量新增错误成员取巧。
3. **迁移到未参与本次拟合的病例**：这种选择性修正是否在训练内部患者留出上仍存在。
4. **实际系统收益**：同预算对照在完整val69上的Overall/Overlap/Pair Dice、IoU、NSD及距离/失败情况是否改善。

**本轮优先补第2层，再推进第3、4层。**读出AUC高、分支有梯度、source略上升、跨过−5、训练loss下降，都不等于第2层通过。

不把“约+1个百分点Overlap Dice”设为每个单步诊断的硬门槛，也不把10^-6量级正差宣布为有效突破。目标量级保留为完整效果目标，不能承诺必达。

## 3. 用现有产物补齐关键训练证据，不先重复训练

### 3.1 先检查fit256，而不是继续只看val69

- 只有起点/终点就报告端点，禁止补造中间轨迹。缺失时只做能补证据的短程重演；状态或序列不完整须标近似重演。
- 实际S/O/P0/P1实验已完成则读取，不重复拟合；未完成就说明，不把“读出一定先通过”当作永久前置闸门。

### 3.2 看真实头结构和信息来源

给出当前737参数头的层结构、实际空间感受野、输入特征来源、归一化及bias/gate/tanh设置。说明它是逐点读取成熟空间特征，还是能新学习局部空间关系。

参数少不自动表示无能力；参数多也不自动有更有用的信息。检查实际结构是否能够表达当前所需的成员边界修正。

分解输出偏置和空间相关部分。对H0、匹配真负、原本正确前景、普通背景分别报告残差分位数及饱和率，不能用全图负均值代替结论。

### 3.3 检查损失到实际更新，而不是只检查配置

沿实跑代码确认BCE、Dice、surface、instance/pair volume的对象、有效区、成员/病例归约与权重。当前完整loss与局部错误诊断loss分开，不把不可分解的Dice/表面项伪造为逐像素贡献。

在固定状态和固定训练batch上，记录：

- 每项loss原始梯度、加权/裁剪后梯度及参数组；
- optimizer真实的学习率、动量/二阶矩、AMP跳步；
- `Δθ = θ_after_step − θ_before_step`；
- 困难目标 `Q_H` 的 `⟨∇Q_H, Δθ⟩` 和同一步前后的实际 `Q_H`；
- 同步检查困难真负成员目标与正确前景是否受损。

`⟨∇Q_H, Δθ⟩`只是一阶局部诊断，不是泛化保证。记录直接更新前后结果。分模块检查，不能只给全模型范数。

额外诊断forward/backward使用独立副本或可恢复状态，避免改变BatchNorm、RNG、optimizer或正常训练序列。大日志按固定里程碑采集，不保存每步全图全部特征。

## 4. 真正运行一次“目标可学习性”检验

### 4.1 数据与任务

从已核验的RAM训练分组中固定一个具有代表性的诊断训练集合，覆盖多个患者、多个成员、普通/EXT_、左右腕和不同错误形态；按诊断规模与成本确定，不按训练结果挑最容易成功的病例。

- 优先承接Metadata.xlsx已经验证的患者分组，不再退回“患者关系未知”。
- 使用fit内样本更新，使用原训练内部患者留出检验，不使用val69选择网络、位置、loss或训练时长。
- C0及旧先验可能见过train425，因此内部留出只说明本次新拟合的病例迁移，不叫整个系统的零样本外部验证。
- 训练仍为完整14成员正负分割任务，可以为诊断目的在训练数据上增加困难样本暴露，但必须包含匹配真负、原有FP和正常正确区域。
- GT可用于训练采样和loss；GT边界距离、真实重叠/成员数、H0标志不能成为推理输入或验证候选过滤器。
- 验证应完整密集预测，或使用预先锁定、仅依赖图像/预测的部署候选；不能只在GT筛选出的H0上评价后宣称系统有效。

固定集合建议沿用已有定义，不为凑数修改：
`H0_k = valid & Y_k=1 & sum(Y)>=2 & final_C0_k<0.5 & source_C0_k<-5.00001`。
固定H0不因当前训练跨过−5就退出跟踪；同时跟踪所有重叠FN、其他错误和新错误，不把H0之外的有效改进忽略。

### 4.2 潜力检验不是再做一个最小头两遍训练

先根据第3节证据决定本次只要检验哪一项阻断：

- **学习信号不对**：在同一个能表达修正的模型上，受控改变目标的作用/归约/有效暴露，观察目标错误是否真正开始被选择性学会；不是随便把正类系数乘大。
- **当前读出表达不足**：允许使用有实际空间感受野、规模足以拟合该诊断任务的成员条件头，而不是默认737参数；必须保留合理的已有信息强参照。
- **冻结表征限制**：有依据时开放一段明确特征路径，并匹配对照；不以原D2一次失败推断所有可训练范围无效。
- **先验/特征缺少可用信息**：先验证新增信息源在相同读出和采样下的增量；不搬同一张图到多个位置碰运气。

这些是决策分支，**不是让你全部跑一遍**。先选择证据最强的一项；最多保留一个不可分开的必要交互，说明为什么需要小型因子对照。

潜力诊断可以有意检验训练集拟合能力，但训练拟合成功不等于信息一定可泛化。读出失败也不能证明图像绝对不可辨。二者都要有独立的留出检查。

### 4.3 干预必须足够有效，不能只满足“参数更新过”

- 训练量依据同一数据反复暴露下的学习曲线确定，不把过去512步/两遍当成结论终点。
- 在run启动前确定最小有效暴露、最大更新数、按暴露计的评价间隔和平台期判断；不能一直训到val涨分才停。
- 先在训练数据检查有效梯度和更新剂量。若加权经过面积映射/归约后几乎不影响目标，属于干预未形成，不得据此否定机制；可在正式比较前做一次有记录的训练侧强度标定，不扫val。
- 不把成熟refiner的尾段极小LR强加给所有新参数；也不统一用新头较大LR重启成熟参数。参数组设置须由实际更新量和数值表现支撑。
- 在现有训练目标、实际特征与可达范围下，若持续有效更新后仍不能在训练病例选择性修正，需更换已定位的限制，而不是无理由延长同一run。
- 新增修正幅度与训练margin的可达性要明确；当前8*tanh已不同于旧±5，不反复拿旧限制解释新头全部失败。更改幅度不能代替获得区分信息。

### 4.4 必须得出的潜力结论

| 观察 | 结论与后续 |
|---|---|
| 训练集H0几乎不动，困难目标实际更新不利 | 优先验证loss交付/优化取舍；不转去S分支 |
| 训练集也学不会，但目标学习信号和参数干预已有效 | 核验读出表达或可训练特征；必要时有依据地扩展，不把失败硬说成无潜力 |
| 能恢复训练H0，但类似负成员等量变差 | 选择性不足；继续加正监督不是答案，检查空间/成员区分与负例 |
| 训练集选择性修正明显，内部留出失败 | 解决泛化、采样与输入信息稳定性，不将训练拟合当成功 |
| 训练与内部留出都有效 | 进入下面的完整同预算验证，不再停留于probe或再写一份新计划 |
| 当前新头有效但S/O无追加作用 | 保留有效修正，暂不强加两图；之后再验证先验价值 |

“明显有效”必须在训练前按该集合错误规模、实际恢复/新增错误和边界代价写定判断依据。不能凭1–2个翻转、微小logit上升或全图loss下降就通过；也不能强制每个小诊断直接达到val +1pp。

## 5. 只根据已定位瓶颈修改到对应环节

每个实际补丁先用几句话写清：**证据是什么 → 哪里阻断 → 为什么这个修改能解除该阻断 → 怎样被实验反驳**。不接受只有“加入注意力”“增强融合”“调大LR”之类的名称。

| 瓶颈证据 | 允许的针对性修改 | 不允许替代为 |
|---|---|---|
| 目标监督被归约/多数易负类/其他项淹没，困难目标实际更新不利 | 改准确的loss作用层、成员暴露、归约或有效权重；原正负GT不变 | 无分析地增加多个新loss、只提高全局正类概率 |
| 当前冻结特征中可读信息足，但头只能校正整体置信度 | 改成员条件读出及实际空间建模，保留容量对照 | 不断加一个更小的标量通道 |
| 高分辨率信息沿某处丢失，且新增特征有留出增量 | 在对应decoder/skip/head处恢复或融合，或开放必要块 | 同时试输入、各层skip、输出并挑最高分 |
| 先验在目标错误处缺乏独立信息，而更合适的图像/成员条件有证据 | 改先验的信息来源或表示；必要时不使用旧先验 | 降阈值、膨胀热力图、用GT替代先验 |
| 训练拟合存在、自然候选负例失控 | 改已定位的选择性、采样代表性或读出泛化；保留难负与全图损失 | 把分类AUC当分割收益、只评GT筛选子集 |

模型位置开放，但遵循计算顺序：step2之后才有的隐特征不能直接进入source之前；需要额外前向就如实计成本。成员修正可增可减，14成员保持独立，不广播“重叠=全部为正”。

保护成熟原件，但不把“所有旧参数必须冻结”“只能在输出后补一刀”“不得改变某项旧loss”当不可推翻的原则。扩容、解冻或替换loss必须由上表证据支持，不为了形式完整而保留有害模块。

- 若希望复用诊断阶段预训练，必须两臂同等处理并披露额外训练；默认重新从共同起点开始。
- 锁定唯一主要变化，匹配样本清单、数据/增强序列、loss（非研究变量时）、优化器策略、可训练范围（非研究变量时）、容量（非研究变量时）、成功更新数、终点与评价。
- 恢复可获得的共同旧参数optimizer/scaler状态；新参数如实新建，缺失旧状态不能伪称精确resume。
- 动态成员选择会随模型分化时如实记录；若需要识别直接机制，统一用预先生成的共同调度，不把处理后的差异隐去。
- 使用能完成有效学习的预算。扩展训练量时reference与variant一起扩展，不拿旧短预算A对比新的长训练候选。

- 候选相对同预算reference是增量证据，相对C0是成熟质量参照；不能仅靠reference被训坏而宣布进步。

评价沿当前**同机、同原R329函数、同padded画布**协议：Overall/Overlap/Pair Dice、IoU、NSD@2px、MSD及原有失败率/体积误差。所有成员、骨对和空集分母固定，不改GT、阈值、canvas或评价器追分。

## 7. 资源和自主执行：给充分实验留空间，但拒绝无界搜索

- 不沿用旧prompt的任意2小时、两遍、512步上限，也不把它们继续当成负结果的充分性证明。
- 用实际单步/整次评价计时、可用显存/磁盘和本地有效学习经验，**在新训练前呈报并锁定本轮整体资源上限**，包含补轨迹、潜力检验、必要对照、完整验证、失败和重演。
- 给出能完成闭环的预计更新量与最晚停止点，不预填“必涨多少”。固定训练内平台期规则和检查频率，防止无休止训练。
- 现有已授权设备内，按呈报的锁与停止规则执行，不每个正常阶段反复请示；新增付费资源、权限扩展或超本轮已锁定总预算才申请确认。
- 预算只够无效干预时，直接说明需要什么资源，不把缩短实验后的微小变化包装成有效检验。不得只跑候选、不跑必要reference。
- 不是允许一次启动所有候选：同一时间只推进一个主瓶颈，最多一个有证据的交互。上一解释被反驳后记录原因，再转向下一项有支持的解释；不保留大串自动搜索队列。
- 出现GT/数据泄漏、数值非有限、成员/坐标错误立即停止相关run并保留失败。科学结果暂时没涨不等于工程失败，但也不授权随意改任务来维持成功叙述。

## 8. 最终交付：要有已执行的决策闭环，而不是又一份空计划

集中在一个隔离目录，复用已有索引，至少交付：

1. `POTENTIAL_AND_INTERVENTION_REPORT.md`：当前头训练能力、主瓶颈证据、实际修改、训练/留出/val效果、下一步决定。
2. `TARGETED_RUN_LOCK.json`：数据、状态、准确代码、主要变量、预定预算、停止与选模规则、实际成本。
3. `TARGETED_TRAINING_TRACE.jsonl`及关键曲线：按目标组和参数组记录实际学习，不只有总loss。
4. `MATCHED_RESULTS.csv`与逐例/成员结果、最小代码diff、可复核checkpoint与测试。

报告开头直接回答：

- **现有头在训练病例上到底能不能学会困难第二成员？**
- **主瓶颈落在目标、读出、特征、泛化还是选择性，证据是什么、哪些仍未确认？**
- **为什么本次修改不是继续微调同一个无效分支？**
- **修正后训练行为是否真的改变，留出是否保持，标准指标净收益多大、代价是什么？**
- **是否值得做完整稳健性验证，还是这条路线应停止？**

未执行写NOT_RUN；诊断/近似回放不能冒充历史实跑；训练拟合不能冒充泛化。无法确认唯一主因时如实给出剩余最小验证，不承诺一定达到1个百分点。

**最终要求：不是更大胆地乱试，而是用足够强、足够充分、可反驳的实验先证明纠错潜力，再修改真正阻断学习的位置，并把内部改善落实到同预算标准分割结果。**
