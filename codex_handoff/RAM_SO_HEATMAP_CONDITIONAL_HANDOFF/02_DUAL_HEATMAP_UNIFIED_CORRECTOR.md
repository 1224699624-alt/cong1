# 02｜两个热力图先验＋一个统一成员条件修正模块

日期：2026-09-29。性质：后续框架与受控分割实验规格。
本轮可以实现原型与保真/回传测试；本文件本身不授权自动启动四组完整分割训练。

## 1. 框架要回答的问题

- S/O是两张软空间提示，不能独立决定具体成员标签。
- 同一个修正器读取当前成员、其他成员、图像/可用细粒度特征和S/O，允许增加或减少当前成员。
- 它应能恢复骨缝、补回正确重叠成员、抑制错误成员并保留已正确区域。
- 以上是预期功能，必须由最终标准指标验证；不是预设“两个先验联动必然更好”。

当前只用RAM 14成员和nnU-Net。TSRS为后续不同标注条件的适配验证，见第10节。

## 2. 默认选择的最小位置：成熟R332之后的共享条件增量

### 2.1 为什么先选这个位置

已有P0强读出可能读取R332 step2的隐特征。这些信息只有step2之后才能获得。
因此，默认采用一个不形成环路的低改动原型：保留C0全部路径，在其最终预测之后添加共享的成员条件增量。

```text
I ──> P_S(I) ──> S ──────────────────────────────┐
I ──> P_O(I) ──> O ──────────────────────────────┤
I ──> C0.nnU-Net ──> Z0, F_high                 │
                      │                         │
                      └─> R332 step1/step2 ──> Z2, F_R
                                                 │
                     当前成员+其他成员上下文 ────┤
                                                 ↓
                              共享条件增量 C_phi ──> ΔZ_k
                                                 ↓
                                           Z*_k = Z2_k + ΔZ_k
```

可将成熟R332与新增共享增量封装为**一个统一修正模块**，但要如实报告内部计算：它仍包含成熟两步和新增读出，不得宣称只有原来的算力或把它画成没有新增计算。

这不是强制最终最佳位置。若读出只使用source之前可得特征且证据支持早期作用，可改为decoder/head附近的一个明确候选，但必须另锁位置；同一次先验消融不能再改变位置。

**不把现有成员refiner直接搬到原图输入端。**它需要初步成员预测；先跑一遍模型再回到输入属于显式反馈，需另算成本，不在本轮默认加入。

### 2.2 共同输入特征

对第k个成员，候选特征为：

`B_k = [I, z2_k, p2_k, own/other-member上下文, F_R,k, 可选F_high]`

统一修正：

`ΔZ_k = C_phi(B_k, S, O)`

`Z*_k = Z2_k + ΔZ_k`

- own/other-member特征优先复用R332真实函数、顺序、范围，不能凭文字重新实现不等价版本。
- 高分辨率F_high只有在P1相对强P0的独立病例/自然负例诊断有增量，或有单独批准的分割对照时加入。若P0已足够，允许先不新增F_high。
- 同一C_phi在成员间共享。默认不新增此前未成功的固定14成员身份表。
- 使用可变成员集合时，max/sum/mean及计数尺度需明确；不擅改现有sum后把差异算给S/O。
- 额外S/O的接口固定为两个独立通道，不相加，不做三态互斥强制，不将S只用于负残差、O只用于正残差。

### 2.3 一个修正器如何同时做两类修正

需要用测试样例检查：

| 情况 | 成员级目标 |
|---|---|
| 目标骨缝背景被某成员预测占据 | 对那个错误成员允许负修正；不能顺便抹去邻近正确骨前景 |
| 真重叠处只预测到A，漏掉B | B允许正修正，A仍保持；不能因此增加所有其他成员 |
| A/B正确，C被误增 | C允许负修正；O高也不能保护错误C |
| 原预测已正确 | 尽量保留；不因S/O高响应强行改动 |
| S/O预测错误或同时高 | 结合图像/成员证据决定；不能让GT仅在此处接管推理 |

GT只用于训练与离线分析，不用于推理状态选择。成员条件来自“正在输出的通道及其预测”，不是由GT告知该像素属于谁。

## 3. 保真与可达范围：既不丢成熟能力，也不重复不可翻转限制

### 3.1 零输出增量必须对齐C0

新头最终层零输出初始化，旧R332残差/gate及nnU-Net权重不改变。

- 在S/O为零或真实图时，初始化`ΔZ=0`都应保持C0。
- 检查source、step1、step2、new_final及mask，容差按同dtype/设备预登记。
- 权重加载必须列出新增/复制的键；不靠大量`strict=False`跳键宣称继承。
- 原有一处零O通道无效是关闭状态的事实，不将其恢复使用后自动称效果改善。

### 3.2 不能让新的头继续被原两步±5范围无意限制

对固定训练H0，记录起点最终margin和新头允许的增量范围。
若新的输出仍被夹回`Z0±5`，那么原来source<-5的hard FN依然不可能恢复。

候选可以是有限有界、可正可负的`ΔZ=b*tanh(a_phi)`，但b尚未确定；只依据train margin、数值稳定与负例保护提出一个值，不能从val最佳恢复数选b。
也可以提出其他保持identity的可学习读出，但必须写明可达性、数值约束和共同对照。

- 本轮不直接放大原R332的2.5上限。
- 不用无限增大新增残差掩盖区分能力不足。
- 若b只覆盖部分训练hard FN，如实报告范围，不要求全部可达才允许研究，但不能宣称已解决所有幅度阻断。
- 两图每种条件使用相同新头、相同幅度规则和参数初始化。

## 4. 与当前P0/P1读出的依赖：不要等待错误的前置条件

- 已通过P1：采用该预先锁定H位置，不重新挑层。
- P0已足够而P1无增量：保留公共B，不强加高分辨率分支。
- 读出只有平衡分类AUC而自然Q误报失控：先不开展基于它的新分割长训。
- 读出未完成：可实现S/O张量接口及零输出保真，但不假装F_high有效。
- probe的Q针对强负第二成员，不覆盖骨缝删FP任务。**统一修正器不能把该Q当成唯一训练/推理区域**，否则它不可能同时承担S相关修正。
- probe最终分数不能直接写入成员mask。分割新头使用原成员GT重新训练，标准0.5不被probe阈值替换。

## 5. 训练目标：先保留一套共同的成员与边界目标，不让热力图同时改loss

对最终`Z*`施加真实独立成员分割损失；可复用经核验R332的BCE/Dice、surface/volume项。

概念式：

`L_corr = L_member(Z*, Y, known) + λ_geo L_existing_geometry(Z*,Y,known) + λ_reg L_small_change`

- 这不是替代本地实际公式。确切损失、系数、分母、source/final深监督先逐项登记；重复几何项不能重复计权。
- 初始S/O信息消融四组的loss完全相同。不能CSO额外加seam/overlap loss，再把总差值归给双热力图。
- 原正负成员一直监督；不只给H0正类。训练应覆盖普通正确区域、错误正成员、非重叠及可信间隙。
- 若R332旧目标只选择4成员，记录新头对其余成员是否存在真实监督。可以统一采用明确的14成员分块loss，但这是新协议的共同部分，不在候选一侧单独增加。
- 全成员loss分块要权重等价，不能独立step14次改变effective batch；动态成员选择若保留，记录处理后分化，不声称恒同监督。
- preserve或小改动正则不能在明确需修正处强制精确复制C0。首轮优先使用全GT与同一有限残差，不默认再加复杂teacher/PCGrad。
- routing是否开启是共同配置；若用已修复工具，单独检查base梯度为零时是否把新增头限成零。不同臂不能混用路由策略。

## 6. 分割对照矩阵：先验质量固定，修正器容量固定

### 6.1 四个主要条件

所有臂都是“同一个C0＋相同的新增统一修正器”。C0本身是零追加更新的保护参照，不替代同预算C00。

| 名称 | S输入 | O输入 | 其他信息、网络和loss |
|---|---|---|---|
| `C00` | 0 | 0 | 完全相同 |
| `CS` | 锁定S | 0 | 完全相同 |
| `CO` | 0 | 锁定O | 完全相同 |
| `CSO` | 锁定S | 锁定O | 完全相同 |

- 修正器代码/参数形状一致，所有臂保留两图通道，仅值置零。训练随机种子与公共初始化一致。
- 同一S用于CS/CSO；同一O用于CO/CSO。若01产生改进O，只锁定一版用于该矩阵。
- C00也是有新修正容量的训练对照，不等于“无任何先验的原生nnU-Net”；它保留成熟R332已有成员关系处理。
- 若要比较O旧/新，另做同一修正配置下`O_REF` vs `O_CANDIDATE`，不能在上述矩阵同时换O版本。
- 新头可以读取S/O统一做双向修正，两个零输入臂也应能学习普通读出；不要故意让C00失去共同信息或参数更新。

### 6.2 本轮不一次启动四组

先完成01、已有P0/P1及本文件接口/保真结果，然后提交最小后续比较：

- 当前O取得明确质量增量、S尚不清楚：优先`C00` vs `CO`。
- O未改善而S有可用证据：优先`C00` vs `CS`。
- 两图质量均已明确：计划完整2×2，但预算须能覆盖全部匹配臂和评估。
- 某图质量一般但读出显示条件增量：可以提出一个有依据的小型分割对照，不把任意检测阈值当永久闸门；明确其试验性质。
- 没有任何选择性信息证据：先做来源/图像/标签独立复核，不为框架完整强行长训。

已有合法同协议臂可复用；新任务不能自动获得旧预算。先选一个问题、一个位置，不再一次试输入/skip/head/输出多个结构。

### 6.3 匹配与初始化

- 默认先冻结C0骨架及成熟R332，只更新新共享头。新头有独立optimizer，不能声称恢复了它不存在的历史Adam。
- 若白盒证据显示必须更新source或某一特征块，另锁同样范围并用于全部对应对照，恢复真正配套的旧状态，不重启高LR破坏成熟模块。
- 先验生成器默认冻结，保证比较的是同一份条件信息。未来全联合微调可单列，不是当前的强制前置。
- 数据序列、增强、采样、实际成功步数、原有成员调度、精度、选模和标准评价一致。
- 0.01 Overlap Dice即1个百分点，是用户目标量级，不是承诺；单seed小试不能证明稳定改善。

## 7. 白盒验证与标准效果：两层都要过

记录层次：

1. S/O经生成、对齐、融合后的值与特征量级，是否被忽略或饱和。
2. 每个相关loss的梯度，到新增头及其他可训练参数组的路径。
3. optimizer真实输入、状态和`Δθ=θ_after−θ_before`，不能只看raw梯度。
4. 每成员`Z0/Z1/Z2/Z*`、signed residual、分位数、上限命中、固定H0恢复与普通成员FP/FN变化。
5. 骨缝场景中错误前景减少与正确骨前景损失；重叠场景中正确第二成员恢复与错误第三成员新增。这些是诊断，不新造主指标。
6. 每臂自己的before/after，不能拿C00的source当别的臂的source。

标准输出沿锁定原R329：Overall/Overlap/Pair DSC、IoU、NSD@2px、MSD及failure、既有RAVD/VOE。
- global count>=2、逐骨成员、骨对交集三个对象分开。
- 不因S更好看就只用gap代理，不因O Dice提高就隐藏NSD/Pair代价。
- 来源代码、分辨率、空集及平均方式不变；标准实现若需对齐原论文，先对同预测单列结果，不覆写历史。
- 主要因果收益相对同预算C00；相对零更新C0同时报告以保护成熟能力，但二者用途不同。
- CSO−CS说明O在有S时的增量，CSO−CO说明S在有O时的增量；只有CSO比C00好不能证明两图都贡献。
- “两个热力图联动有效”必须有相应对照，不能只靠敏感性图或将两个独立增益相加。

容忍度、最低有意义收益及选择规则按用户已有要求预登记，不事后放宽追认。极小负差不自动叫严重退化，也不是已证明非劣效。

## 9. 当结果不符合预期时怎么处理

| 结果 | 正确处理 |
|---|---|
| 先验检测改善，CO标准分割无增量 | 保留“图更好”结论，查已有信息冗余、可读性与实际更新；不宣布成功 |
| 新头C00本身优于C0，CS/CO并无额外收益 | 收益主要是读出/容量/继续训练，不归给S/O |
| CS有效、CO无效或有害 | 允许当前阶段只保留S；完善O前不强加到默认模型 |
| CO有效、CS破坏重叠或Recall | 先核验S语义与负修正，不能用手工S×(1−O)遮盖错误 |
| CSO仅优于C00、不优于强单图 | 只能说组合有用，不能说两图互补增量已经证明 |
| H0恢复但新增FP或NSD恶化 | 不晋级；区分信息不足与决策范围/成员目标问题 |
| 所有臂很小、曲线仍学习 | 记录有效更新与成本，下一轮共同增加有限预算；不只延长候选 |

不重复已失败的身份张量、D2解冻或纯正监督，除非新证据改变具体假设。不要以“两个创新必须都在”为理由删失败结果。

## 10. TSRS后续补充验证：不是本轮GPU任务

- 标签是图片不是问题；要核验标注的是前景、匿名实例还是解剖类别，是否存在原始多层归属。
- 原生颜色缺跨图身份时，不映射成RAM14通道；单层互斥颜色不提供真实多成员重叠GT。
- RAM先验权重可作为明确来源的迁移条件，但TSRS训练后有效只能证明方法/模块适配有效，不自动叫零样本泛化。
- 默认未来使用TSRS自己的backbone/output与可观测GT，比较相同适配预算的普通修正、+S、+O、+SO；不把TSRS union训练改成O=0。
- 若输出只有一个union mask，不能宣称已验证完整多成员交互；若做匿名实例必须先有无GT的自动实例候选和对应评价。
- 可变K修正器的mean/max/sum尺度和排列行为先验证。不要为了TSRS另开一套大型实例检测课题。
- RAM当前2D医学数据来源不因TSRS是儿童就自动统一年龄/疾病含义；对各数据如实描述。
- TSRS开发集不叫独立外部盲测；新的留出划分和授权须单列，不悄悄混入当前RAM训练。

## 11. 本文件现在要交什么

`CONDITIONAL_CORRECTOR_READY.md`应包含：

1. 选定的唯一位置与实际层名，是否依赖P0/P1结果；
2. C0保留路径、新增输入/参数、S/O接口及真实前向图；
3. 零增量保真、成员语义、范围、无泄漏测试；
4. 共同训练目标、参数组和可观测监督；
5. 优先后续pair及完整2×2的预计成本、标准判据和停止条件；
6. 哪些已运行、哪些只实现、哪些尚未确认。

完整分割训练须在用户确认该锁与预算后执行。本轮允许把框架写好、测试好，不能因为O稍有改善就自动启动全部CSO长训。
