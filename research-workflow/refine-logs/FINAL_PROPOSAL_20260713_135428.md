# Research Proposal: Heterochrony-Aware Prediction-Derived Separation Prior (HA-PDSP)

## 核心主张

不为儿童手部建立固定平均形状，而是学习一个冻结的发育条件关系先验：整手 X 光提供全局发育上下文，基础模型已提出的候选位置提供局部骨化证据，统一的 class-conditional relation posterior 判断两个候选是否应保持分离，再用 max-min foreground bridge energy 惩罚错误粘连。

## 1. 输入和边界

- 仅 `TSRS_RSNA-Epiphysis`；不混入 Articular-Surface。
- hand ROI、左右手方向、旋转和尺度使用确定性归一化，推理时不得使用 GT。
- chronological age 只在真实元数据存在时输入；RSNA `boneage` 是 radiographic bone age，只能在 original-train 作可删除 teacher。
- sex 是带 shrinkage 的弱条件，不建立男女硬模板。
- 当前 mask 只支持骨骺中心、面积、相对位置、间距与 gap，不支持完整指骨/shaft length。

## 2. 全局发育上下文与候选触发的局部证据

```text
F = Encoder(x)
z_g = GlobalPosterior(GlobalPool(F), age_if_available, sex)
a_i = PatchPool(F, stopgrad(candidate_center_i), frozen_radius_rule)
```

`z_g` 是整手发育 posterior；`a_i` 只称 local radiographic/ossification evidence。它只能在基础模型已经产生的 candidate center 上读取，不能生成、移动或补回节点，也不输出 heatmap/mask。prior pretraining 完成后 encoder 与 relation model 一起冻结，供所有目标 backbone 共用。

## 3. 统一 prediction-derived graph

synthetic、OOF、训练和推理 soft masks 全部使用同一 stop-gradient 管线：

```text
probability normalization -> distance transform -> peaks -> watershed
-> hand-normalized nodes -> Delaunay edges -> frozen edge cap
```

节点无固定实例身份。缺少骨化中心时不创建虚拟节点，空图 abstain。

## 4. 发育条件关系 posterior

严格分离 image/context conditioner 和 prediction-derived geometry：

```text
c_ij = [z_g, a_i, a_j, coarse coordinates,
        sex/chronological_age_if_available]

u_ij = [relative center displacement,
        log basin-area ratio,
        normalized basin scales]
```

```text
sigma_y = sigma_min + softplus(raw_sigma_y)
p(u_ij | y_sep,c_ij) = N(mu_y(c_ij), diag(sigma_y^2(c_ij)))
P(y_sep | u_ij,c_ij) ∝ p(u_ij|y_sep,c_ij) P(y_sep|c_ij)
```

默认使用单 Gaussian。只有统一 original-val NLL/calibration 明确证明必要时才整体升级为小 K mixture，禁止按 backbone 选择。`sigma_y` 表达 aleatoric developmental variation，而不是 OOD veto。

## 5. 训练先验

训练样本仅来自 original-train：

- bridge corruption：不同 GT provenance，`y_sep=1`；
- over-split corruption：同一 GT provenance，`y_sep=0`；
- small geometry/appearance jitter；
- patient-disjoint OOF soft predictions：candidate 只看 prediction，GT 只在 edge 已产生后赋 provenance label。

删除 masked reconstruction、component dropout、presence/count 支线和独立 classifier/density 双头。

## 6. 只基于可靠性的 activation gate

```text
c_context = [z_g,a_i,a_j,coarse coordinates,
             acquisition/image-quality representation]

w_ij = P(y_sep=1 | u_ij,c_ij)
     * c_epi(c_context)
     * c_candidate
     * c_stability
```

`c_epi` 禁止读取 mask-derived geometry、gap、Conn 或 bridge strength。异常 geometry 是需要修复的证据，不能变成 abstention 理由。候选 basin 可靠性与增强稳定性分别由 `c_candidate`、`c_stability` 控制。

## 7. 反向拓扑 bridge energy

```text
r_0 = stopgrad(source_seed)
r_{t+1} = max(r_0, min(p_crop, MaxPool3x3(r_t)))
T = 64
Conn_ij = mean(r_T[target_seed])

E_sep = sum(w_ij * Conn_ij) / (eps + sum(w_ij))
```

该能量计算 strongest max-min foreground path，只惩罚本应分开的候选之间存在高置信前景桥，不鼓励骨头前景连通。

## 8. 跨模型统一接口

```text
g_n = ||dL_native/dl||_2
g_p = ||dE_sep/dl||_2

if no_edge or g_p < tau_g:
    L = L_native
else:
    alpha = clip(rho * stopgrad(g_n/(g_p+eps)), alpha_min, alpha_max)
    L = L_native + alpha * E_sep
```

prior、candidate rules、calibration、gate、gradient ratio 和 warm-up 全部冻结，跨 nnU-Net、ARAA、YOLO+SAM 的可训练 mask head/refiner、DINOv3/U-Net 等共用。

## 9. 审计图而非训练模块

```text
V = stopgrad(abs(dE_sep/dl))
```

只用于 bridge 热图、intervention area 和案例审计，不反馈 loss、不 mask gradient、不参与更新。

## 10. 文献机制取舍

- 保留 plug-and-play regularizer 的独立预训练与冻结复用；
- 保留 SSM 的 variance-aware relation，但不生成平均 shape mask；
- 保留 Explicit SPM 的 global/local 分工，但 local 只在已有候选位置池化；
- 保留 Deep Closing 的 topology corruption，但反转为背景骨缝 separation；
- 保留 TEDS 的 topology/geometry 分离，但不固定 topology；
- 保留 Fast χ 的 violation localization，仅作解释，不设固定 Euler target 或 correction network。

## 11. 最小验证边界（当前不执行）

- 同一冻结 prior 接入 5 个异构模型；报告 gap FP、merge rate、component-count MAE、Boundary IoU/F1、Surface Dice、HD95/ASSD，并对 Dice/IoU/Recall 做非劣检验。
- 每模型报告 candidate coverage、activation、abstention、harmful activation。
- synthetic-only vs synthetic+OOF；global-only vs global+candidate-local evidence；无 epistemic gate。
- leave-one-backbone-out 检验 unseen-backbone transfer。
- 所有开发限 original train/val；clean-test-v2 只在完全冻结后作一次 R201 final evaluation。
