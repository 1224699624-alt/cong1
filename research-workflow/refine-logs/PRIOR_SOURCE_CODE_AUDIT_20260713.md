# 儿童骨骺分割先验相关源码审计（2026-07-13）

## 审计目的与边界

本次只审计 5 个公开仓库中可用于当前儿童手部骨骺分割方向的实现思想，不启动实验、不修改现有模型，也不把任何仓库整体并入工程。

当前目标仍是：保留骨头掩膜作为唯一硬标签，用年龄（骨龄）、性别和图像证据构造条件关系先验；先验只产生停止梯度的关系置信系数，损失只增强标签中已经存在的可靠背景/边界监督，不凭空生成骨缝标签。

## 总结结论

5 个仓库中，没有可原样移植的完整方案。最值得吸收的是三个互补机制：

1. **PatellaSeg：方差感知的先验可信度。** 不同年龄、性别和解剖关系的稳定程度不同，先验权重应随统计方差和样本支持度变化。
2. **DeepClosing 与 Universal Topology Refinement：合成破坏 + 局部关键区域训练。** 可主动制造“假粘连、边界膨胀、局部缺口”等错误，只在被破坏且标签可靠的位置计算加强损失。
3. **Explicit Shape Priors：先验自身更新与图像证据交互应分工。** 但应改造成骨对关系原型，不采用稠密形状张量，也不嵌入每个骨干网络内部。

TEDS-Net 的固定拓扑形变机制不适合骨化中心数量随发育变化的儿童数据，主要作为反例和初始化参考。

## 关键风险发现

### PatellaSeg 存在 GT 泄漏，不能照搬

公开实现的 `score_test()` 使用 `mask_img` 参与测试图候选评分，`clustering()` / `eval()` 又调用该路径。因此它展示的融合效果不能被当作 GT-free 推理选择器。当前项目若借鉴，只能重新实现训练集统计得到的方差与系数计算，验证/测试推理不得读取该图 GT。

此外，方差除法未见稳定的 epsilon 保护，模糊 KNN 中距离与分数的语义也需重新核对，不能复制实现细节。

### 固定拓扑与儿童发育变化冲突

TEDS-Net、传统 SSM 和部分拓扑损失默认组件数或拓扑结构应固定。但本任务中，骨龄不同会导致骨化中心出现、融合和尺寸比例发生真实变化。把某一年龄段的组件数量固化，会把正常发育差异误判为拓扑错误。

### 拓扑修复方向可能相反

DeepClosing 面向管状前景重连，而当前问题是相邻骨之间的错误前景桥。直接使用 closing 或保持前景连通，会强化粘连。简单点约束也可能阻止一次本来必要的“断桥”拓扑变化。

### 许可证风险

本地快照中只有 DeepClosing 发现明确的顶层 `LICENSE`。其余仓库只有 README 或未见顶层许可证。在确认授权前，只能借鉴论文思想并独立重写，不应复制源码。

## 对当前方法的具体完善

### 1. 把先验从“平均形状”改成“条件骨对关系分布”

对每一个有解剖意义的相邻骨对 `(i,j)`，在训练集内按骨龄和性别估计低维关系：

- 两骨中心的相对方向；
- 经手掌尺度归一化后的中心距离；
- 两骨相对长度、宽度或面积比；
- 最近边界距离；
- 可选的局部图像沟谷/边缘响应。

不保存一张固定模板 mask，而保存条件均值、协方差、样本支持数和缺失率。骨龄用连续核或邻近年龄窗平滑，不建议切成许多硬年龄段，否则稀疏年龄段会不稳定。

### 2. 将“年龄段欠缺”显式变成置信度，而不是隐藏问题

先验系数应同时受三类证据控制：

`k_ij = support_confidence × relation_consistency × image_evidence`

- `support_confidence`：该骨龄、性别附近训练样本越少，权重越低；
- `relation_consistency`：当前骨对关系偏离条件分布越远，先验越谨慎；
- `image_evidence`：局部 X 光确有暗沟、双边缘或低前景置信时，才增强骨缝相关损失。

因此年龄分布不平衡不会被假装消失，也不会让少数年龄段的统计先验强行控制模型。它会表现为可记录、可校准的低支持区间。

### 3. 用“关系原型库”吸收 Explicit Shape Priors 的优点

可以维护少量条件关系原型，例如“某骨龄附近、某性别、某相邻骨对”的距离/方向/比例分布。原型只输入到统一的先验模块，输出标量或骨对级系数；不输出像素掩膜，不在 U-Net、nnU-Net、DeepLab 等骨干内部各写一套交叉注意力。

这样才能保持跨模型实验中的方法一致：更换骨干时，先验定义和损失接口不变，论文才能合理声称提升来自通用先验/损失，而不是某个专属结构。

### 4. 用合成“假粘连”训练机制，而非生成反向骨缝标签

借鉴 DeepClosing 和 Universal Refinement 的 corruption 思路，在训练期对标签已经明确为背景的窄间隙附近，构造受控错误：

- 将两个邻近骨的预测概率局部抬高，模拟假桥；
- 对骨边界做小尺度概率膨胀，模拟边界模糊；
- 对低对比区域加入局部混淆，但不改原始硬标签；
- 记录每次 corruption 的位置、宽度、强度和涉及骨对。

PCR-Loss 只在原标签为 `y=0`、且局部证据和条件关系都足够可靠的像素增强负类惩罚。如果原标签本身把两骨连在一起，没有可靠背景像素，则跳过该 pair，不伪造骨缝。

### 5. 把拓扑违规图用于诊断，不用于替代标注

可实现轻量的粘连/边界违规热图，展示训练过程中哪些骨对持续出现高前景桥接概率，并记录：

- 每个 epoch 的高风险骨对数量；
- 风险区域面积与最大桥宽；
- 可靠负像素上的平均前景概率；
- `k_ij` 的均值、分位数及其与年龄支持度的关系；
- 原模型与改进模型在同一局部 ROI 的概率剖面变化。

这类热图只作为训练分析、论文机制图和验证诊断，不作为 clean-test-v2 上的阈值选择依据，也不直接修改预测 mask。

## 推荐优先级

1. **优先实现：PatellaSeg 启发的支持度/方差感知系数。** 它直接解决年龄分布不均和发育差异问题。
2. **第二优先：面向假粘连的 corruption + 可靠区域 PCR-Loss。** 它最贴近最终希望展示的骨缝与边界改善。
3. **第三优先：统一的低维条件关系原型库。** 只有在简单统计先验不足时再增加学习能力。
4. **仅诊断：违规热图、简单点和 Euler 类分析。** 不放进推理主链。
5. **拒绝：固定拓扑形变、稠密模板分割、前景 closing、GT 参与的测试融合。**

## 后续实现前应先确定的接口

在写代码前，应冻结一个跨骨干统一接口：输入只包括训练/推理时合法获得的信息，输出 `k_ij`、可靠负区域权重及诊断统计。骨龄若在真实推理流程中不可获得，则只能作为训练教师，推理端需使用图像估计的发育表征或对骨龄边缘化，不能直接读取真实骨龄。

本审计不改变 clean-test-v2 的锁定规则；所有先验分布、窗口、阈值和权重都只能在训练集与 original-val 上建立和选择。
