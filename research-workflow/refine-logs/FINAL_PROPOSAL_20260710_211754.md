# Research Proposal: Prediction-Derived Developmental Separation Prior (PD-DSP)

## 核心问题

儿童手部骨骺的数量、尺度、相对位置与间距随性别、年龄和个体成熟度异步变化，固定 shape atlas 或固定组件数会把正常发育差异误判为分割错误。本方法只约束“预测中的两个局部候选是否应保持背景分隔”，不规定完整前景形状。

## 方法

1. **全局发育 posterior**：X 光经无 spatial decoder 的全局 encoder 得到低维 `z_dev`。真实 chronological age 仅在确实存在时使用；RSNA `boneage` 明确作为 radiographic bone age，只可在 original-train 作可删除的 ordinal teacher；sex 是带 shrinkage 的弱协变量。
2. **统一 prediction-derived graph**：所有 clean/corrupt soft masks 与各基础模型输出都走同一固定 distance-transform、peak、watershed、hand-normalized Delaunay 管线。节点默认无命名，只含区域位置、面积、间距、尺度和置信度。
3. **关系先验**：候选通过 GT provenance 学习 `P(should separate | z_dev, sex, regional geometry, confidence)`。不同 GT component 为正例，同一 component 的 over-split 为负例，混合或背景候选 ignore。
4. **负空间能量**：在每条候选边的 `64×64` crop 上计算 max-min fuzzy foreground connectivity：

```text
r_0 = stopgrad(source_seed)
r_{t+1} = max(r_0, min(p_crop, MaxPool3x3(r_t)))
T = 64
Conn_ij = mean(r_T[target_seed])
```

它等于最强 source-target 路径上的最低前景概率，只惩罚高置信前景桥，不会累计微弱背景响应。

5. **跨模型接口**：冻结先验后，对所有模型使用相同 logits-space gradient ratio：

```text
alpha = clip(rho * stopgrad(||dL_native/dl|| / (||dE_sep/dl|| + eps)),
             alpha_min, alpha_max)
L = L_native + alpha * E_sep
```

无有效边或 prior gradient 过小时跳过 prior term。所有常量仅在 original train/val 冻结一次，跨 backbone 共用。

## 数据能力边界

现有 epiphysis masks 可以支持骨骺中心 presence、面积、相对位置、中心间距与 gap width；不能直接支持完整指骨长度、shaft width 或关节轴。若需要这些量，必须新增可靠 landmark/shaft annotation，不能从当前标签中虚构。

## 儿童异步发育的表达

- 年龄/性别只定义群体分布，不形成硬模板；
- X 光将群体分布更新为个体成熟 posterior；
- posterior variance 对同龄早熟、晚熟及罕见发育状态进行不确定性表达；
- 组件数量由 prediction-derived graph 观察，缺失中心时不生成虚拟 slot；
- 不确定或候选不稳定时 abstain，不强制切割。

## 验证边界

冻结同一 prior、候选算法和梯度规则后接入 nnU-Net、ARAA、YOLO+SAM、DINOv3/U-Net 和 high-resolution U-Net。主指标为 Boundary IoU/F1、Surface Dice 2px/5px、HD95、ASSD、gap FP、merge rate、component-count MAE；Dice/IoU/Recall 做非劣检验。全部选择只用 original train/val；clean-test-v2 仅作一次 R201 最终评估。
