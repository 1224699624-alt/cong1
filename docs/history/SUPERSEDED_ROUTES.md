# 被取代研究路线与停滞原因总结 (Superseded Routes)

> 本文件旨在系统记录历史上曾探索但已被证明**无效、低效或存在根本缺陷**的研究路线。
> **核心作用**：防止后续研究者或自主 Agent 再次盲目重复已证伪的方案、重启已被废弃的训练脚本。

---

## 路线 1：早期 YOLO + SAM / MedSAM / HQ-SAM Prompt-Refiner 路线

### 方案概述
使用 YOLO 检测骨骼目标，提取边界框（Bounding Box）或粗中心点，作为 SAM / MedSAM / HQ-SAM 的 Prompt 输入，期望借助基础分割大模型的泛化能力实现解剖结构细化。

### 为什么停止（致命缺陷与证据）
1. **框 Prompt 语义丢失**：
   - 目标骨骼与相邻骨骼间的骨缝往往只有 1~3 个像素宽。边界框同时包含了正样本骨骼与紧贴的相邻负样本骨骼，SAM 极易发生“跨骨缝膨胀”或“漏分割细长骨骼突起”。
2. **过平滑破坏解剖形态**：
   - SAM/MedSAM 倾向于生成边缘连续且平滑的掩码，这在自然图像中是优势，但在骨龄 X 光片中会抹平细微骨纹、导致相邻骨骼接触面粘连（False Merge）。
3. **指标瓶颈**：
   - 早期 R001~R038 实验表明，即使在 Oracle 最佳调优下，SAM 方案依然无法匹敌医学专用的 nnU-Net 强基线。

### 替代与后继
- 转向医学专用高分辨率网络、nnU-Net 密集预测骨骼像素以及显式建模解剖接触关系的先验机制。

## 路线 2：R188~R198 基于通用检测头（如 MaskDINO/Detectron2）的端到端实例分割

### 方案概述
尝试将通用计算机视觉领域的 SOTA 实例分割框架（MaskDINO、Detectron2、Swin-Transformer 骨干）引入骨骼全器官分割，期望通过注意力机制（Queries）直接区分相互接触的骨骼实例。

### 为什么停止（致命缺陷与证据）
1. **小样本高精度数据下极易过拟合**：
   - MaskDINO 等大规模 Transformer 架构在单图过拟合测试（R195）和极少样本测试中虽然能快速收敛，但在全量验证集上泛化极差，出现严重的预测坍塌。
2. **微小骨缝无感知**：
   - 基于 Query-based 的密集目标检测对于密集接触的骨端、微小骨骺边界定位精度低，大量相邻实例预测框发生交叉重叠。
3. **工程维护极其沉重**：
   - 依赖复杂的 Detectron2 C++/CUDA 扩展与特定环境编译（R189），无法保证跨环境的可复现性与敏捷迭代。

### 替代与后继
- 明确放弃通用复杂检测框架，聚焦于全卷积/轻量级医学精细分割架构。

## 路线 3：R351 强耦合双先验联合迁移方案

### 方案概述
试图在输入端加入骨缝先验适配器，输出端级联重叠成员补全网络，并将 RAM 数据集训练得到的先验模型直接迁移至 TSRS 数据集，实现双向、端到端、多任务联合训练。

### 为什么停止（致命缺陷与证据）
1. **多重未收敛模块互相干扰**：
   - 输入骨缝先验与输出重叠先验在训练时同时调整，导致梯度信号冲突，无法辨别哪个模块真正起效，产生负向耦合。
2. **跨数据集标签定义漂移（Domain & Label Protocol Shift）**：
   - TSRS 原始标签无法表达真实的多重成员归属（Overlap），其真实重叠标签为未知状态。强制把 RAM 学习到的 overlap prior 迁移过去，导致 TSRS 的 gapFP 和 merge 指标不升反降（相比 R350 明显回退）。
3. **冗余代码爆炸**：
   - 产生了大量针对 R351 的单次专用数据读取与训练脚本（如 `train_r351_*.py`），维护成本极高。

### 替代与后继
- 演化为 V3 / V3.1 协议，并在 2026-09-29 正式将 S（骨缝先验）与 O（重叠先验）解耦为独立语义的热力图，坚持“独立质量评估 → 统一条件输入”的分步验证原则。

## 路线 4：协议演化：V2.1 → V3 → V3.1 过程中的过度设计

### 方案概述
在 V2.1 到 V3.1 演化期间，曾设计了包含复杂的“身份上下文（Identity-Context）”、“Q-限域空间”、“全局协调器（Coordinator）”以及基于复杂多阶段推理的庞大系统。

### 为什么停止（致命缺陷与证据）
1. **身份上下文因果验证为负**：
   - 2026-09-22 的严格对齐实验（`ram_identity_causal_20260922`）证明，打乱骨骼身份顺序与规范顺序相比，Overlap DSC 增量仅为 0.000027（置信区间穿过 0），未能恢复任何关键难例。说明所谓的身份依赖纯属冗余计算。
2. **过度工程化增加误差累积**：
   - 阶段越多，前序阶段的误差对后序阶段的影响呈级联放大，增加了整体调试与定位的困难。

### 替代与后继
- 简化协议，废除复杂的 Q 限域和身份表回路，统一到低参数量的轻量级条件修正头（仅 737 参数）。

## 路线 5：2026-09-22 ~ 09-29 RAM 细粒度调优与梯度分支失败链

### 1. Source 目标梯度强化 (2026-09-24)
- **探索**：给未能召回的困难正样本直接注入 source 梯度的正向监督。
- **停止原因**：Overlap DSC 虽有微弱改善，但 Overlap NSD 下降，未恢复最难的 71,335 个像素，未达性能门槛。
- **结论**：**不应继续使用简单的目标梯度拉扯**。

### 2. GT-Negative Guard 局部负例保护 (2026-09-22)
- **探索**：引入显式的真实负样本惩罚项，试图压制假阳性。
- **停止原因**：减少 2441 个 FP 的代价是同时增加了 2404 个 FN，边界结构反而恶化，整体指标不增反降。
- **结论**：**严禁在无解剖自适应权重的条件下暴力加压负例损失**。

### 3. H0 Final-Logit 局部监督 (2026-09-24)
- **探索**：将 H0 唯一像素直接监督在最终 14 成员的 final logit 上。
- **停止原因**：虽然梯度能反向传播，但 Overlap Dice 反而下降 0.003925 个百分点，多造成 1,604 个成员 FN。
- **结论**：**放弃在最终 Logit 上直接硬加局部 H0 正向监督**。

### 4. O 先验接入位置搜索 (2026-09-28)
- **探索**：比较将 O 先验输入到 nnU-Net 第一卷积层（INPUT_O）与输入到 Refiner 第一卷积层（REFINER_O）。
- **停止原因**：test124 严格评测显示，`INPUT_O (0.873789)` 和 `REFINER_O (0.873814)` 均劣于等算力的零先验 `ZERO (0.874588)`。
- **结论**：**单纯变换网络入口位置无济于事，先验本身信息的质量才是决定性瓶颈，禁止再把算力浪费在入口排列组合搜索上**。

### 5. 高分辨率特征直接读出 P1 (2026-09-28)
- **探索**：使用更深层/更高分辨率的 decoder 特征尝试读出难例信号。
- **停止原因**：P1 相比 P0 无稳定增量，且背景负例误报急剧失控（精确 FP 高达 16.5 万）。
- **结论**：**在特征本身判别力未证实前，不启动全网络高分辨率分割训练**。

### 6. C00 vs CS 09-29 实测 (2026-09-29)
- **探索**：在冻结基准上，单独开启 S（骨缝先验）条件修正头与关闭先验（C00）对比。
- **停止原因**：holdout 与 val 上 CS 相比 C00 的变化量在小数点后第 6 位（`−0.00000136`），且造成个别正确边缘微小损失。
- **结论**：**证明当前 S 先验尚未在实际假连接处产生足以驱动宏观 Dice 提升的有效增量，禁止直接开展全量 SO 联合长训，必须先定向审计 S 先验在真骨缝位置的信息纯度**。
