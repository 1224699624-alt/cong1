# 掌骨骨骺分割最佳版本专利交底说明

生成日期：2026-07-03

本文只整理当前最佳效果版本真实涉及的技术路线：**强基础掩膜 + 补充候选掩膜 + 候选分歧区 patch 级局部仲裁**。文档中的模块说明和权利要求方向均围绕这一路线展开，不在本文中直接绘制流程图或写入公式。

## 1. 一句话概括

本方案面向儿童手部 X 线片中的掌骨骨骺分割。它不是重新训练一个单一分割模型，也不是把多个模型结果简单投票，而是先得到一个较稳定的基础掩膜，再引入一个具有互补性的候选掩膜，只在二者结果不一致的局部区域内，用 patch 级仲裁网络判断是否接受候选掩膜的局部修正，最终得到更稳的骨骺分割结果。

通俗地说：一个模型先给出“主答案”，另一个模型提供“补充意见”。系统不盲目相信补充意见，而是只检查两者不一致的局部小区域，并通过一个小型判断网络决定要不要改主答案。

## 2. 当前最佳版本应如何描述

当前最佳版本可在交底书中描述为：

> 一种基于候选掩膜分歧区域的局部仲裁分割方法。该方法以第一骨骺掩膜作为基础结果，以第二骨骺掩膜作为补充候选，在二者存在差异的局部区域内提取图像块和掩膜差异特征，通过局部仲裁模型判断该区域采用基础掩膜、候选掩膜或保持不变，从而输出最终骨骺分割掩膜。

不建议在交底书或权利要求中出现内部实验编号、具体数据集名称、具体评价数值。正式专利中可以写“在实施例中，相比单独基础掩膜，能够改善局部边界和减少候选掩膜造成的误修正”。

## 3. 建议发明名称

首选名称：

**一种基于候选掩膜分歧区域局部仲裁的掌骨骨骺医学图像分割方法及系统**

备选名称：

1. 一种用于手部 X 线骨骺分割的基础掩膜与候选掩膜局部仲裁方法
2. 一种基于 patch 级掩膜修正判别的掌骨骨骺分割方法及系统
3. 一种候选掩膜互补引导的 X 线骨骺区域分割方法

## 4. 要解决的技术问题

儿童手部 X 线骨骺分割中，单个模型往往存在各自偏差：

- 稳定的基础模型通常整体表现较好，但在少数边界或细小区域仍有漏分、边界偏差；
- 高召回的候选模型能补充一些基础模型漏掉的像素，但也容易带来多分、粘连或假阳性；
- 简单投票、并集或全图融合容易把候选模型的错误一起引入；
- 只依赖整图级选择也不够细，因为同一张图内可能部分区域基础结果更好，部分区域候选结果更好。

因此，本方案要解决的问题是：**如何只吸收候选掩膜中真正有帮助的局部区域，同时避免候选掩膜的错误区域破坏基础结果。**

## 5. 总体技术方案

总体流程包括五个部分：

1. **图像输入与预处理**  
   输入手部 X 线图像，进行灰度归一化、尺寸调整等基础预处理。

2. **基础掩膜生成**  
   使用第一分割模型输出基础骨骺掩膜。该基础掩膜作为默认保留结果。

3. **补充候选掩膜生成**  
   使用第二分割模型输出候选骨骺掩膜。该候选掩膜通常具有不同的特征来源或分割倾向，用于提供可能的局部补充。

4. **分歧区域定位与 patch 构建**  
   比较基础掩膜和候选掩膜，定位二者不一致的区域，并围绕这些区域裁剪局部图像块。

5. **patch 级局部仲裁与最终输出**  
   局部仲裁模型根据图像块、基础掩膜块、候选掩膜块和二者差异特征，判断该区域是否接受候选修正，最后组合得到最终掩膜。

## 6. 核心模块

### 6.1 基础掩膜生成模块

基础掩膜生成模块用于得到一个整体稳定的骨骺分割结果。该模块可以采用任意医学图像分割模型、提示式分割模型或经过后处理的组合模型。专利中不建议限定具体模型名称。

撰写时可以把它描述成“第一分割器”，作用是给出默认可信的骨骺区域。基础掩膜不是最终答案，而是后续局部修正的基准。

### 6.2 候选掩膜生成模块

候选掩膜生成模块用于提供与基础掩膜互补的分割结果。候选掩膜可以来自另一个分割模型，也可以来自同一模型的不同参数、不同提示方式或不同后处理方式。
撰写时可以把它描述成“第二分割器”，作用是提供可能修正基础掩膜的候选区域。候选掩膜通常具有更强的补充能力，但也可能引入误分，因此不能直接全图替换基础掩膜。

### 6.3 分歧区域定位模块

本模块只关注基础掩膜和候选掩膜不一致的位置。这样可以避免对整幅图进行不必要修改，降低错误候选被引入的风险。
撰写者可以参考相关论文中的分歧区域、注意力区域或候选区域生成方式，自行写成公式或流程图。本文不固定具体公式，以免过早限制权利要求范围。

### 6.4 patch 构建模块

对分歧区域中的像素或连通区域，裁剪局部 patch。每个 patch 可以包含：

- 原始 X 线图像局部块；
- 基础掩膜局部块；
- 候选掩膜局部块；
- 基础与候选的差异图；
- 可选的边界图或距离图。

这里的重点是把“原始图像证据”和“两个掩膜的差异证据”一起送入局部判断模块，而不是只根据单个模型的置信度做决定。

### 6.5 patch 级局部仲裁模块

局部仲裁模块判断每个 patch 中是否应该接受候选掩膜的局部修正。它可以是小型 CNN、轻量 Transformer、MLP 或其他分类/分割判别器。
撰写者可以把该模块画成一个小型判别网络：输入为原图 patch、基础掩膜 patch、候选掩膜 patch 和差异 patch，输出为“接受候选修正”或“保持基础掩膜”。具体网络结构、损失函数和阈值规则可参考后文论文。

### 6.6 保守回退模块

为了避免候选掩膜造成误修正，本方案设置保守回退逻辑。当局部仲裁模型置信度不足，或者该区域的候选修正面积过大、形态异常时，保持基础掩膜不变。

保守回退可以写成规则模块，也可以写成局部仲裁模型输出后的门控模块。专利撰写者可根据权利要求宽度需要决定是否把它作为独立从属特征。

## 7. 初步权利要求方向

### 7.1 方法权利要求

一种掌骨骨骺区域分割方法，包括：

- 获取手部 X 线图像；
- 通过第一分割器生成基础骨骺掩膜；
- 通过第二分割器生成候选骨骺掩膜；
- 根据基础骨骺掩膜和候选骨骺掩膜确定分歧区域；
- 围绕分歧区域构建局部图像块；
- 将局部图像块、基础掩膜块和候选掩膜块输入局部仲裁模型；
- 根据局部仲裁模型的输出决定是否采用候选掩膜对基础掩膜进行局部修正；
- 输出最终骨骺分割掩膜。

### 7.2 系统权利要求

一种医学图像分割系统，包括：

- 图像预处理单元；
- 基础掩膜生成单元；
- 候选掩膜生成单元；
- 分歧区域定位单元；
- 局部 patch 构建单元；
- 局部仲裁单元；
- 保守回退单元；
- 分割结果输出单元。

### 7.3 存储介质权利要求

一种非暂态计算机可读存储介质，其上存储有计算机程序，所述计算机程序被处理器执行时实现上述方法。

## 8. 可作为从属权利要求的细节

从属权利要求可以覆盖：

- 所述分歧区域由基础掩膜和候选掩膜的异或区域确定；
- 所述分歧区域经形态学膨胀后作为局部可编辑区域；
- 所述局部 patch 包括原始图像块、基础掩膜块、候选掩膜块和差异掩膜块；
- 所述局部仲裁模型为卷积神经网络、轻量 Transformer 或多层感知机；
- 所述局部仲裁模型输出接受候选修正的概率；
- 当接受概率低于阈值时保持基础掩膜不变；
- 当候选修正导致局部面积或连通域变化超过阈值时保持基础掩膜不变；
- 所述候选分割器与基础分割器采用不同的特征提取骨干、训练策略、提示方式或后处理方式；
- 所述最终掩膜由基础掩膜和被接受的候选局部修正区域组合得到。

## 10. 初步可专利性判断

该方案相对更适合主张的创新点是：

- 不对整幅图进行全局融合，而是只在基础掩膜和候选掩膜不一致的位置进行局部判断；
- 将原图 patch、基础掩膜 patch、候选掩膜 patch 和差异图共同作为仲裁输入；
- 通过局部仲裁模型判断是否接受候选修正；
- 设置保守回退机制，避免候选掩膜错误破坏稳定基础结果；
- 适用于掌骨骨骺这类小目标、多实例、边界细、容易局部误分的 X 线分割任务。

不建议把发明点写成“使用某个具体模型”，因为单独的 U-Net、SAM、MedSAM、Transformer、DINO、ConvNeXt 等都属于公开技术。建议把具体模型放在实施例中，权利要求中使用“第一分割器”“第二分割器”“局部仲裁模型”等通用表述。

## 11. 不建议写进正式专利的内容

- 不建议出现内部实验编号；
- 不建议出现具体实验指标数值；
- 不建议写入未参与最佳版本的后续规划模块；
- 不建议把桥接抑制作为独立核心模块，除非后续有使用该模块并带来最佳效果的版本；
- 不建议限定必须使用 YOLO、SAM、DINO、ConvNeXt 等具体模型名称；
- 不建议把测试集名称写入正式权利要求。
